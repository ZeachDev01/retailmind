# Super Administrator Control Center

## Mode

Operate.

## User outcome

The Super Administrator must scan platform risks rapidly, select the highest-priority condition, and follow an explicit resolution path without losing system context.

## Approved composition

**Radar + Resolution** — `.impeccable/mocks/decision/superadmin-radar-resolution.png`

The first viewport combines:

- a compact risk horizon for critical conditions, Platform health, Demand Forecast health, and access readiness;
- a severity-ranked issue queue using only real dashboard attention items;
- a persistent three-step resolution workbench for the selected issue;
- a lower readiness ledger for recovery, backup, Store continuity, and technical controls.

## Direction contract

**World:** RetailMind’s established Working Stockroom operational room: Control Navy structure, Action Blue interaction, cool worksurfaces, exact semantic state colors, thin rules, quiet depth.

**First viewport:** A dense but calm control room. Risks are readable before scrolling. The highest-severity issue is selected by default and its explanation, destination, and verification step are visible beside the queue.

**Signature interaction:** Selecting an issue updates the resolution workbench in place. The primary action opens the correct existing control; the final step asks the operator to refresh and verify that the condition cleared.

**Motion grammar:** One short workbench content transition using opacity and vertical position, with content visible by default and reduced-motion support.

**Responsive behavior:** Desktop uses a queue/workbench split. Tablet and mobile stack the risk horizon, queue, and workbench without hiding any action; controls remain at least 44px high.

**Product-truth constraint:** The comp’s invented example incidents and metrics are not literalized. Only values and destinations returned by `DashboardWorkspace` appear in the built surface.

**Honest risk:** The information density can become noisy; alignment, restrained semantic color, and one blue action voice must keep the page calm.
