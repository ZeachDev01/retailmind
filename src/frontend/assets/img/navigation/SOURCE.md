# Navigation SVG source

Icons8 Flat Color Icons, used under the MIT option offered in LICENSE.md.

Source: https://github.com/icons8/flat-color-icons

Pinned revision: 1bf90d5ff118bc6690120ff9fdfe234565b7e414

Only selected SVG assets are vendored. GCash remains the separate existing brandmark.

Exceptions: `notification.svg` reuses RetailMind's existing bell geometry with amber fills; `close.svg` uses a simple red X. These RetailMind control assets preserve familiar navigation symbols where the upstream set has no equivalent.

`expand.svg`, `collapse.svg`, and `external.svg` reuse Bootstrap Icons v1.11.3 (the existing application icon family) in blue, preserving the recognizable fullscreen and logout symbols. Source: https://github.com/twbs/icons/tree/v1.11.3/icons ; license: bootstrap-icons-LICENSE.txt.
